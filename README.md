### 💼 Production & Showcase Portfolio

#### 🌐 Web Engineering & Enterprise Systems
- **[Asabr Corporate Portal & Redesign](https://github.com/ExRen/Asabr-new)**
  - Comprehensive modern re-architecture of corporate web infrastructure using **Next.js 14 App Router**, **TypeScript**, and **Tailwind CSS**.
  - Integrated fluid page transitions via **Framer Motion**, responsive layouts translated 1:1 from Figma design systems, and dynamic multi-platform social feeds (YouTube API & custom news scrapers).
- **[JobTracker Bims](https://github.com/ExRen/JobTrackerBims)**
  - Full-stack career and job application management platform built with **Next.js**, **TypeScript**, and **Tailwind**.
  - Features custom **PWA** implementation with service workers for full offline reliability, along with type-safe schema validation via **Zod**.
- **[E-Commerce Platform with Midtrans](https://github.com/ExRen)**
  - Complete digital storefront architecture featuring cart management, checkout flows, and automated payment gateway callbacks via **Midtrans Snap & Core API**.
- **[SuperApp KORKOM / DRMS Portal](https://github.com/ExRen)**
  - Corporate communications and document management system built for structured internal file handling, access control, and dynamic tracking.

#### 🤖 Automation, Crawlers & Bot Frameworks
- **[Autonomous YouTube Shorts Generator](https://github.com/ExRen/YouTube-shorts-generator)**
  - End-to-end automated content engine: queries Reddit discussions, synthesizes voice narration, edits background video tracks using `moviepy`, and publishes automatically through Google OAuth & YouTube Data API.
- **[Auto-Clip AI Studio](https://github.com/ExRen)**
  - AI video processor using **OpenAI Whisper** and **PyTorch** for automatic silence detection, speech-synchronized subtitle rendering, and vertical video cropping.
- **[WhatsApp Automation Suite (Bot Reminder & WeddingSend)](https://github.com/ExRen/WhatsAppBotReminder)**
  - Multi-device WhatsApp messaging daemons with persistent scheduler engines (`node-cron`), templating, and cloud persistence via **Supabase**.
- **[OSINT & Social Intelligence Scrapers](https://github.com/ExRen)**
  - Suite of targeted crawlers covering Instagram, TikTok, LinkedIn, and Google Maps with anti-detection handling and structured exports (JSON, CSV, Excel).
